# Storm Keeper

A small roguelike deckbuilder battle in Godot 4, from the Ludo video "How to make a game like Slay the Spire in Godot":
a lighthouse keeper plays cards against a crab knight and an anglerfish on a stormy shore. Every card, fighter, icon,
animation, background and sound was made with Ludo (ludo.ai); the code is ours.

Open the folder in Godot 4 and press Play: the battle plays itself (four fights in a row, with a card reward or a relic between them).
Run it from the command line with arguments after `--`:

```
godot --path .                     # the played run, as in the video
godot --path . -- mode=show        # the showcase: the deck fanned, a card taken apart, the deck by type
godot --path . -- slow=0.35        # the whole game, the sea too, in slow motion
```

Where things are:

- `card.tscn` + `card.gd`: one card scene (the art clipped to the frame's window, the frame, the tinted ribbon, the cost and the text).
- `card_data.gd` + `cards/*.tres`: each card's numbers and picture; a new card is a new `.tres` file, not new code.
- `main.gd`: the battle (the hand fan, hover and play tweens, the turn loop, enemy intents, damage through block, rewards, sound).
- `flash.gdshader`: the white hit flash.
- `art/bg/`: the background loop as JPEG frames, read at run time (the folder has a `.gdignore`). To export a build, add `art/bg/*` to
  the export preset's "Filters to export non-resource files/folders" (Project > Export > Resources); running in the editor needs nothing.

## Holiday packs: Winter Lights (Christmas) and Hallow's Tide (Halloween)

From the Ludo video "Claude Code Game Assets: A Christmas Update for My Godot Game": an AI agent (Claude Code) driving the Ludo CLI
made two themed packs for this game. Every card, fighter, icon, relic, the card frame, the energy orb, the moving background, all
eleven animations of the three fighters, the seven sounds and a music loop come in a Christmas and a Halloween version.

```
godot --path . -- pack=winter-lights   # the Christmas pack
godot --path . -- pack=hallows-tide    # the Halloween pack
godot --path .                         # the storm it shipped with
```

Or set the project setting `storm_keeper/pack` to the pack's folder name. Both packs work with `mode=show` and `slow=` too.

How it works:

- A pack is a folder, `packs/<name>/`, holding only the files it changes, at the same paths and pixel sizes as the originals
  (`art/...`, `sfx/...`, `art/anim/anims.json`, the `art/bg/` frames), plus `music.mp3`. A new pack is a new folder, not new code.
- `packs.gd` (an autoload, `Packs`) swaps every picture and resource of the pack in before the battle loads
  (`Resource.take_over_path`, so each `load("res://art/...")` and every card `.tres` gets the pack's picture) and plays the pack's
  music on a loop. With no pack it runs exactly as it shipped.
- `main.gd` changed by three lines: the three things the battle reads straight from disk (`anims.json`, the sounds and the
  background frames) ask `Packs.file()` for their path. `project.godot` gained the autoload.
- Each fighter's sheets were packed with the free `ludo toolbox sprite pack` to one frame size and one ground line, and drawn at the
  original's size; `art/anim/anims.json` in each pack holds the new frame counts, speeds and strike times (the hit lands on each new
  attack's furthest frame).
- To export a build with a pack, add `packs/*/art/bg/*` to the export filter next to `art/bg/*` (see above).

How the packs were made: Edit Image changed each original picture from a text prompt (two takes each, one kept); the
cards that show a fighter got that pack's new fighter still as the reference image, so the cards draw the same Santa-hatted
or witch-hatted keeper. Every animation was made again from the new still with the original's own motion prompt and frame count.
The prompts below are word for word.
